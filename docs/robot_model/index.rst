Robot Model
===========

This section documents the Littlebot robot description and its representation
within Gazebo.

Topics:

- URDF and Xacro organization.
- Robot links and joints.
- Visual, collision, and inertial properties.
- Differential-drive model.
- Sensor and actuator representation.

The current robot description is a basic model. Additional physical and
functional properties will be documented as they are implemented.
