Littlebot Gazebo Documentation
==============================

Welcome to the technical documentation of the Littlebot Gazebo simulation
subsystem.

This repository provides the simulation resources used to develop and test
the Littlebot robot within Gazebo environments.

The documentation describes the simulation architecture, robot model,
simulation environments, and development workflow.
